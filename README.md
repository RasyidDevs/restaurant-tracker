# restaurant-tracker

Dashboard monitoring restoran berbasis Computer Vision (DineSight).

## Fitur
1. Waiting time setelah pesan
2. Lama pelanggan di meja
3. Reserved table
4. Deteksi makanan/minuman dari luar & jumlah orang di meja
5. Rasio orang terhadap piring dan gelas
6. AI insight & rekomendasi aksi
7. Estimasi bangku segera kosong
8. Alert piring tanpa orang > 5 menit
9. Peringatan kendaraan terlalu lama di parkiran

## Menjalankan
```bash
npm install
npm run dev
```

Stack: React + Vite + TypeScript + Tailwind CSS + Recharts. Data saat ini masih dummy (`src/data/mock.ts`).
